# Snakes at Work · Rắn công sở

A 21-day interactive game for growing executive stakeholder-management skills. Fail a conversation and your stakeholder turns into an office snake; fail too often and you become one. Replay to charm them back.

Play: GitHub Pages, deployed from the `main` branch, root folder, serves `index.html`.

All people, companies and projects in the game are fictional.

Source is in `app/`, the build is `build.mjs`, tests are in `tests/`, narration tooling is in `voice/`. See PROGRESS.md, QA.md, SECURITY.md and DESIGN.md.
